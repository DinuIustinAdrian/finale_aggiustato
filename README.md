# Esercizio 3.1 corso Data Science, gruppo 1

### Consegna
Creare un programma per la gestione di una sala cinematografica. Il programma deve permettere di creare una sala 5x10 e modificarla in maniera interattiva. La visualizzazione su terminale utilizzera "L" per indicare un posto libero e "X" per indicare un posto già occupato.

## Desrizione file

`gestione_sala.py` Funzioni che riguardano la modifica, visualizzazione e inserimento prenotazioni.

`salvataggio.py` Funzioni per leggere/scrivere file o variabili.

`main.py` Programma principale dove vengono utilizzate le funzioni all'interno di `salvataggio.py` e ` gestione_sala.py`
